BINGO POP V3 — by BROT2YOU

Déployer index.html à la racine du dépôt Bingo-pop sur GitHub Pages.
La V3 conserve les fonctionnalités de la V2 et ajoute une interface Studio.
Le boulier illustré sur l’accueil est décoratif; le boulier interactif 3D est dans Tirage.
Three.js nécessite une connexion Internet lors du chargement.
Avant remplacement, exporter vos bingos et conserver une copie de l’ancienne version.
